# Чек-лист интеграции с Яндекс Играми

Работа идёт по списку документации: **одна ссылка → реализация → проверка → коммит**.
В таблице — что именно сделано по каждой странице и где это лежит в коде.

Легенда: ✅ сделано и проверено · 🟡 частично / требует ручной проверки в Консоли · ⬜ ещё не взято в работу

## Как проверяется

| Команда | Что проверяет |
| --- | --- |
| `npm run build` | сборка игры одним файлом `dist/index.html` |
| `npm run yandex:check` | требования к архиву: размер, имена файлов, `index.html` в корне, подключение `/sdk.js` выше кода игры |
| `npm run test:profile` | юнит-тесты на мок-SDK: звук (остановка при потере фокуса, независимые защёлки, работа без Web Audio), системный плеер (сканирование исходников на медиаэлементы и Media Session), облачный прогресс (лимиты, батчинг, слияние), флаги, реклама (кулдаун, награда, выключенные флаги, работа вне Яндекса), покупки (каталог, отмена, порядок «начислить → сохранить → погасить», повторная выдача без дубля), лидерборды (лимиты, кэш, скрытый профиль, формат счёта, отправка без авторизации), окружение и переходы по акции (разбор `referrer`, маршрутизация `inapp_id`/`promo_intent`, `promoId` в `getFlags`, работа вне Яндекса), ежедневная награда (серверные сутки против часов устройства, серия и её сброс, максимум, дата из будущего, слияние с облаком, работа вне Яндекса) |
| `npm run yandex:sdk-check` | живые вызовы SDK в headless-браузере с подменённым `/sdk.js`: `init → LoadingAPI.ready → GameplayAPI.start/stop`, облачные данные, флаги, полный цикл рекламы (забег → итоги → rewarded → возврат), магазин (каталог, покупка, алмазы, платное возрождение, выдача незакрытой покупки на старте) и лидерборды (топ по вкладке, `setScore` за забег, место на экране итогов), а также кооператив (загрузка сессий, транзакции соперников в панели отряда, отметка о финише), оценка игры (кнопка после canReview, диалог по клику, повтор не предлагается), ярлык (кнопка после canShowPrompt, окно по клику, начисление алмазов) переходы по акции (магазин по `inapp_id` с подсветкой покупки, магазин по `promo_intent`, обычный старт по сезонной акции, `promoId` в `getFlags`) ежедневная награда (начисление по клику, запись в облако, повторный клик ничего не даёт, выросший бонус на следующих серверных сутках) события платформы (диалог выхода по `HISTORY_BACK`, «Остаться» без выхода, «Выйти» с `dispatchEvent(EXIT)`, возврат в меню после закрытия диалога выбора аккаунта), объекты SDK (полный экран по кнопке в настройках, копирование итога в `clipboard.writeText`, сенсорное управление по `deviceInfo`), подключение SDK (полный набор колбэков рекламы, готовность игры при асинхронно пришедшем `/sdk.js`), требование 1.3 (звук глохнет по `blur` и `visibilitychange` и возвращается с фокусом и видимостью вкладки) и требование 1.6.*.5 (в DOM нет медиаэлементов, игра не пишет в медиасессию) |
