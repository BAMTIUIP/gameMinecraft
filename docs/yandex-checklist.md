## Как проверяется

| Команда | Что проверяет |
| --- | --- |
| `npm run build` | сборка игры одним файлом `dist/index.html` |
| `npm run yandex:check` | требования к архиву: размер, имена файлов, `index.html` в корне, подключение `/sdk.js` выше кода игры |
| `npm run test:profile` | юнит-тесты на мок-SDK: локализация (ключи ×4 языка, подстановки, отсутствие пустых строк и английских заимствований), звук и системный плеер, облачный прогресс и миграция без старого валютного баланса, флаги, реклама, бесплатные rewarded-наборы, прямые SKU-покупки (каталог, отмена, durable receipt до `consumePurchase`, восстановление без дублей), лидерборды, окружение и промо-маршруты, ежедневные supplies (UTC, серия, cloud merge, офлайн), события и пульт ТВ |
| `npm run yandex:sdk-check` | живые вызовы SDK в headless-браузере с мок `/sdk.js`: загрузка, облачные данные и флаги, rewarded-видео/возрождение и interstitial, магазин (цены и иконки из каталога, прямая покупка SKU, запись и восстановление receipts до consume, отсутствие виртуального баланса и платного возрождения, отдельный `disable_ads`), сохранение и выдача бесплатных рекламных supplies, лидерборды, кооператив, оценка игры, ярлык с разовым supply-набором, промо-переходы, серверная daily-награда, события платформы, fullscreen/clipboard, сенсорный ввод, четыре языка и адаптация для ТВ |
| `npm run yandex:shots` | съёмка скриншотов реального геймплея для карточки магазина (п. 5.1.1.2 и 8.3.4): чистая сборка без интерфейса платформы, кадры складываются в `docs/shots/` |
