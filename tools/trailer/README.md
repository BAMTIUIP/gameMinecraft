# Запись промо-трейлера ORE RUSH

Локальный инструмент (не попадает в сборку игры): поднимает dev-сервер, ведёт
headless-браузер по заскриптованному маршруту и складывает кадры, затем кодирует
их в MP4. Сцена готовится через dev-only хук `window.__ore` (`src/game/devHook.ts`),
а геймплей (движение, камера, бой, ИИ питомцев) — настоящий, движком без подмены.

Сценарий: меню → «Исследователь» → инвентарь → питомец-птица → идёт к воде →
третий person на ходу → прыжок в воду → первый person на нырке → плывёт вниз и
вперёд ~1 с → разворот к птице над водой → третий person → всплытие и заплыв на
берег → прыжок на суше и смена питомца на волка в воздухе → бег к дереву → рубка
ствола (волк несёт ресурсы) → первый person + меч → монстры впереди → волк
выпрыгивает сзади и атакует → тёмный экран → титры **ORE RUSH** шрифтом и цветом
из меню → обложка `docs/ore-rush-cover.png` → конец.

## Требования

- Node.js 20+ и `npm install` в корне репозитория (ставит `puppeteer-core` и
  `@sparticuz/chromium`; chromium скачивается при установке, ~150 МБ).
- ffmpeg. Любой из вариантов:
  - macOS: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg`
  - или `pip install imageio-ffmpeg` — инструмент найдёт его сам через `python3`.
- (Опционально) свой Chrome вместо скачанного: `export CHROME_PATH=/path/to/chrome`.

## Запись

Вертикальный ролик 9:16 (попугай):

```bash
node tools/trailer/record.mjs record --aspect=9x16 --out=tools/trailer/.frames/v1
node tools/trailer/record.mjs encode --frames=tools/trailer/.frames/v1 --aspect=9x16 \
  --out=docs/ore-rush-gameplay-vertical.mp4 --mci
```

Горизонтальный ролик 16:9 (попугай):

```bash
node tools/trailer/record.mjs record --aspect=16x9 --out=tools/trailer/.frames/h1
node tools/trailer/record.mjs encode --frames=tools/trailer/.frames/h1 --aspect=16x9 \
  --out=docs/ore-rush-gameplay-horizontal.mp4 --mci
```

Вариант с сычом вместо попугая (9:16):

```bash
node tools/trailer/record.mjs record --aspect=9x16 --out=tools/trailer/.frames/owl1 --bird=owl
node tools/trailer/record.mjs encode --frames=tools/trailer/.frames/owl1 --aspect=9x16 \
  --out=docs/ore-rush-gameplay-vertical-owl.mp4 --mci
```

Или одной командой (запись + кодирование, кадры удалятся после успеха):

```bash
node tools/trailer/record.mjs record --aspect=9x16 --out=tools/trailer/.frames/v1 \
  --encode=docs/ore-rush-gameplay-vertical.mp4 --mci
```

Каждая запись занимает ~1-2 минуты (старт dev-сервера, генерация мира, прогрев
рендера, ~26 с самого ролика). Кодирование — ~1 минута.

## Полезные флаги

| флаг | зачем |
|---|---|
| `--bird=parrot\|owl` | какой питомец-птица в начале (по умолчанию `parrot`) |
| `--seed=N` | зерно мира (по умолчанию `192379` — вся область съёмки ровная, без зимы и пустынь) |
| `--mci` | интерполяция до 30 fps (плавнее, если захват шёл медленнее) |
| `--fps=60` | целевой fps итогового видео (по умолчанию 30) |
| `--capture-scale=0.5` | захват в пониженном разрешении + апскейл (для слабых машин без GPU; на нормальной видеокарте не нужен) |
| `--trace` | печатать позу игрока каждые 500 мс (диагностика тайминга) |
| `--keep-frames` | не удалять кадры после `--encode` |

## Требования к роликам (проверяются автоматически)

MP4, высота от 400 px, длительность до 28 с, размер до 100 МБ. Инструмент сам
выдаст ошибку, если лимиты превышены. Итоговые размеры: 720×1280 (9:16) и
1280×720 (16:9) — это минимумы, которые просит Яндекс; частота кадров — 30.

## Как это устроено (если захочется поменять сцену)

- `src/game/devHook.ts` — dev-only хук: выравнивание ландшафта, пруд, дерево,
  телепорт, спавн мобов, выдача предметов, pre-mesh чанков. В продакшен не
  попадает (`import.meta.env.DEV`, в `dist` проверено отсутствие).
- `tools/trailer/record.mjs` — оркестратор: dev-сервер, браузер, скринкаст,
  таймлайн, кодирование. Таймлайн событийный: отбивки ждут реальных событий
  игрока (достиг кромки / вошёл в воду / вышел на берег / добежал до дерева),
  поэтому он устойчив к любой частоте кадров.
- `tools/trailer/fonts/` — шрифты меню (Pixelify Sans + Space Grotesk) для
  офлайн-записи, куда нет доступа к Google Fonts.
- кадры складываются во временную папку `tools/trailer/.frames/` (в .gitignore).

## Частые проблемы

- **Медленно / рывки** — на машине без GPU (или в облаке) движок проседает до
  5-15 fps. Помогает `--capture-scale=0.5` и `--mci`; на обычной видеокарте
  ничего добавлять не нужно.
- **Не находит ffmpeg** — поставьте системный ffmpeg или
  `pip install imageio-ffmpeg`.
- **Прерванная запись оставила dev-сервер** — при следующем запуске рекордер сам
  убирает свои протекшие серверы (узнаёт их по сигнатуре `vite --port N --strictPort`).
  Твой ручной `npm run dev` (без `--strictPort`) под раздачу не попадает.
- **Не находит Chrome** — дождитесь окончания `npm install` (скачивание chromium)
  или задайте `CHROME_PATH`.
- **Игрок не доплыл до берега / пронёсся мимо дерева** — так и задумано в коде:
  выход на берег — удержание прыжка у кромки, спринт — с самонаведением; если
  меняли таймлайн, не убирайте эти механики.
